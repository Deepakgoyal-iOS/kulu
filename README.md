# kulu

This project shows the list of products and it's details.

What all we need to complete this project - 
- Basic Network Architecture
  - Service Class
  - Response Handler
  - Request Interceptor (to return error if no internet)
  - Response Interceptor ( No needed in our project but will contruct a basic class)
  - API Repository
 
- Utilities -
  - NetworkConnection (for status of internet connection)
  - ImageDownloader
    - Image Caching logic
    
- Product List View Controller
  - Table View
  - Custom Cell (to show product)
  - Pagination on cell visibility
  - Error ( A full page error or footer error )
  - View for footer error / full page error

- Product Detail View Controller
  - ScrollView with VStack to show product details
 
- KEY HIGHLIGHTS -
  - We will use programatic constraints for UI
